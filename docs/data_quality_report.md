## 已修复问题：混合日期格式

TfL 新版字段 `Start date` 并不始终使用 ISO 格式。2024 年部分文件使用 `DD/MM/YYYY HH:MM`，而同年其他文件仍使用 `YYYY-MM-DD HH:MM`。pandas 对混合日期统一开启或关闭 `dayfirst` 都会让其中一种格式发生日月倒置。

修复策略：

1. 以 `YYYY-` 开头的值按 ISO/year-first 解析。
2. 其他斜杠日期按 day-first 解析。
3. 回归测试同时覆盖 `2024-01-08`、`2024-08-01`、`01/08/2024` 和 `08/01/2024`。
4. 重跑 242 个批次、58,865,471 条行程，重新生成小时缓存与看板。

## 全量 OD 审计

流式处理在小时分析之外继续执行三层过滤：有效出发时间、1-180 分钟有效时长、起终站名称非空，并排除 4 个不完整源日期。58,865,471 条源记录中，最终有 58,311,048 条进入 OD 分析。

规范化站名生成 888 个候选站点键。2,902 条站点别名记录中有 97 条因同一源 ID 指向多个候选键而标记为 `requires_review`；这些记录保留原名、源 ID 和有效时间，没有被静默合并。

全量结果中同站归还占 4.10%，跨站行程占 95.90%。跨站 Top20 仅覆盖跨站行程的 0.513%，证明固定 TopN 只能展示头部案例，不能代表总体流动结构。
